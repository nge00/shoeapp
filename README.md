K2그룹 신발 어프로발 대시보드 사용 매뉴얼
==================================================

1. 대시보드 접속
--------------------------------------------------
현재 접속 주소:
https://nge00.github.io/shoeapp/


2. 브랜드 선택 및 대시보드 조회
--------------------------------------------------
K2 GROUP 아래에는 현재 시즌이 표시됩니다.
대시보드 상단의 [브랜드 선택]에서 브랜드를 고릅니다. 별도의 왼쪽 브랜드 선택 메뉴는 없습니다.
선택한 브랜드에 따라 샘플 현황, 요약 수치, 전체 진도율, CFM 진도율이 바뀝니다.
상단의 [실시간 동기화] 버튼을 누르면 서버의 최신 샘플·미팅 변경 내용을 즉시 불러옵니다. 다른 사용자의 변경은 약 4초 간격으로 자동 반영됩니다.
오늘 미팅 예약과 이번 주 미팅 예약 카드에는 완료되지 않은 예약 건수가 표시됩니다.

선택 가능한 브랜드:
K2, 아이더, WIDEANGLE, 다이나핏, 노르디스크, NEPA,
K2 Safety, EIDER SAFETY, NEPA SAFETY

브랜드별 진도율 표에는 전체 아이템 수, 컨펌 아이템 수,
생산시화 아이템 수, 완료 수, 전체 진도율, CFM 진도율이 표시됩니다.


3. 샘플 등록 및 수정
--------------------------------------------------
1) 상단의 [샘플 등록]을 누릅니다.
2) 브랜드, 샘플명, 시즌(예: 2027SS, 2027FW), 담당 MD, 담당 디자이너를 입력합니다.
3) 진행 상태를 선택합니다.
4) 1차 어프로발은 20%, 2차 어프로발은 40%, CFM 어프로발은 70%, 생산시화는 100% 진도율로 자동 저장됩니다. 샘플 사진도 등록할 수 있고, 진도 현황에서 샘플명 앞에 표시됩니다. 등록 시즌은 K2 GROUP 아래 선택창에서 골라 해당 시즌 현황을 확인합니다.

진행 상태 선택 목록:
1차 어프로발, 2차 어프로발, 3차 어프로발,
CFM 어프로발, 생산시화, 재시화

등록된 샘플은 샘플 진행 현황 표에서 [편집]을 눌러 수정할 수 있습니다.
샘플 코드는 입력하지 않습니다.
같은 아이템의 상태를 [재시화]로 저장하면 기존 진도율을 유지합니다.
왼쪽 [샘플 관리]에서 브랜드와 등록된 샘플을 선택하고 [샘플명 수정]을 눌러 샘플 정보를 바꿀 수 있습니다. 샘플 진행 현황 표에는 해당 샘플의 미팅 진행일이 표시됩니다.


4. 샘플 미팅 예약 및 완료 처리
--------------------------------------------------
1) [미팅 예약]을 누릅니다.
2) 브랜드를 선택하면 해당 브랜드에 등록된 샘플명이 목록에 표시됩니다. 진행 상태, 예약자, 날짜, 시간을 입력합니다.
시간은 07:30~18:30 사이에서 30분 단위입니다. 날짜를 선택하면 모든 브랜드의 미완료 예약 시간이 회색으로 표시됩니다. Supabase에서도 날짜·시간 슬롯을 트랜잭션 잠금으로 검사하므로 동시에 접수된 브랜드 간 중복 예약도 저장되지 않습니다. 미팅 완료 후 슬롯을 다시 예약할 수 있습니다.
3) 장소를 미팅룸 A~D 중에서 선택하고 [예약 등록]을 누릅니다.
4) 예약된 미팅은 [어프로발 미팅 예약] 영역에 표시됩니다.
5) 미팅이 끝나면 해당 예약의 [미팅 완료]를 누릅니다.

미팅을 완료하면 샘플 진행 상태가 해당 미팅 상태로 바뀝니다. 완료된 예약은 예약 목록에서
숨겨지고 오늘/이번 주 예약 건수에서 제외됩니다.


5. 진도율 집계 기준
--------------------------------------------------
전체 진도율:
브랜드에 등록된 전체 샘플 수를 기준으로 계산합니다.
해당 브랜드의 샘플명과 일치하는 생산시화 또는 재시화 미팅을 완료 처리하면
그 샘플은 전체 진도율 집계에서 100%로 계산됩니다.
1~3차 어프로발과 CFM 어프로발 미팅은 전체 진도율에 포함하지 않습니다.

CFM 진도율:
브랜드에 등록된 전체 샘플 수를 기준으로 계산합니다.
해당 브랜드의 샘플명과 일치하는 CFM 어프로발 미팅을 완료 처리하면
그 샘플은 CFM 진도율 집계에 반영됩니다.

샘플명과 브랜드가 예약 정보와 샘플 등록 정보에서 일치해야 해당 아이템에
진도율이 반영됩니다. 샘플명은 같은 표기로 입력해 주세요.


6. 데이터 및 사용자 권한 안내
--------------------------------------------------
샘플과 미팅 정보는 서버 폴더의 shared-data.json 파일에 저장됩니다.
이 파일을 직접 편집하거나 삭제하지 마세요.

현재 로그인/회원가입 기능은 없습니다. 사내망 접속 주소를 사용할 수 있는 사람은
샘플과 미팅 내용을 조회하고 수정할 수 있습니다. 공유 대상은 사내 사용자로 제한하고,
서버 폴더 접근 권한도 적절히 관리해 주세요.

## 전 브랜드 예약 시간 중복 방지 업데이트 (2026-10)

최신 `supabase-setup.sql`을 Supabase SQL Editor에서 다시 실행해 공용 예약 시간 조회 RPC와 원자적 중복 방지 트리거를 설치하세요. 기존 브랜드별 데이터는 유지됩니다. 이후 `index.html`을 GitHub Pages에 배포하면 예약 화면이 전 브랜드의 예약 시간대를 표시합니다. 기존 중복 예약이 이미 데이터에 있는 경우에는 그 예약을 정리한 뒤 적용해야 합니다.

## 시즌별 진행률

샘플 등록에서 시즌을 직접 입력합니다(예: 2027SS, 2027FW). K2 GROUP 아래 시즌 선택창에서 시즌별 샘플·미팅·진도율을 볼 수 있습니다. CFM 어프로발 등록은 진도율 70% 및 CFM 완료 집계, 생산시화 등록은 100% 및 전체 완료 집계로 반영됩니다.

## 예약 수정·삭제 및 진도 엑셀 내보내기
- 미팅 예약 목록에서 미팅 완료, 일정 변경, 예약 삭제를 할 수 있습니다. 일정 변경 시 같은 날짜·시간의 다른 예약과 충돌하는지 확인합니다.
- 샘플 관리에서 브랜드와 시즌을 선택하고 등록 샘플을 선택하면 샘플을 삭제할 수 있습니다. 확인 후 선택 샘플에 연결된 미팅도 함께 삭제됩니다.
- 브랜드별 진도율의 [엑셀 내보내기]는 현재 선택한 시즌·브랜드 기준으로 진도 요약, 샘플 현황, 미팅 현황이 포함된 Excel 호환 `.xls` 통합 문서를 내려받습니다.
