K2그룹 신발 어프로발 인터넷 사용자 매뉴얼
2026-10-30
==================================================

1. 접속 및 회원 권한
--------------------------------------------------
인터넷 주소: https://nge00.github.io/shoeapp/
회원가입 후 로그인하면 회원은 본인 계정에 연결된 브랜드 자료를 조회·수정할 수 있습니다. 관리자는 관리자 계정으로 전체 브랜드, 샘플, 예약 및 관리 일정을 관리합니다. 인터넷 배포본의 데이터는 Supabase에 저장되며 사내 서버의 shared-data.json과 자동 동기화되지 않습니다.

2. 대시보드와 샘플 관리
--------------------------------------------------
상단 시즌 및 브랜드 선택으로 해당 자료를 확인합니다. 샘플 현황, 오늘·이번 주 미완료 미팅 수, 전체 진도율 및 CFM 진도율이 표시됩니다. Egress 사용을 줄이기 위해 4초 간격 자동 동기화는 꺼져 있습니다. 다른 사용자의 변경 사항을 확인하려면 상단 [실시간 동기화]를 누르세요. 로그인 후 화면에 처음 들어올 때는 서버에서 최신 자료를 한 번 불러옵니다.

샘플 등록에서 브랜드, 샘플명, 시즌, 담당 MD, 담당 디자이너, 진행 상태, 진도율과 비고를 입력합니다. CFM 어프로발은 70%, 생산시화는 100%로 자동 입력됩니다. 샘플 현황에서 편집할 수 있고, 샘플 관리에서 샘플명 수정 및 삭제가 가능합니다. 샘플 삭제 시 연결된 미팅도 삭제되므로 확인 후 진행합니다.

진행 상태: 1차 어프로발, 2차 어프로발, 3차 어프로발, CFM 어프로발, 생산시화, 재시화.

3. 미팅 예약
--------------------------------------------------
1) [미팅 예약]에서 브랜드, 샘플, 진행 상태, 예약자, 날짜, 시간, 장소를 입력합니다.
2) 샘플과 시간은 여러 개 선택할 수 있습니다. 같은 예약 요청에서 선택한 샘플과 시간의 조합별로 예약이 생성됩니다.
3) 예약 가능 시간은 08:00~15:30, 30분 간격입니다. 미완료 예약 또는 관리 일정이 있는 시간은 선택할 수 없습니다. 완료 예약은 시간 중복을 막지 않습니다.
4) [예약 등록]을 눌러 저장합니다. 예약 내용은 어프로발 미팅 예약 목록과 예약 달력에서 확인할 수 있습니다.
5) 예약 카드의 [일정 변경]으로 내용을 수정하고 [삭제]로 취소할 수 있습니다. 수정 시 다른 미완료 예약과 시간이 겹치는지 다시 확인합니다.

4. 관리자 신규 예약 알림
--------------------------------------------------
회원이 새 미팅을 예약하면 관리자 화면 우측 하단에만 알림 팝업이 표시됩니다. 팝업에는 브랜드, 샘플, 날짜와 예약 시간, 장소, 예약자 및 진행 상태가 표시됩니다.

같은 예약 요청에서 한 샘플에 여러 시간이 지정되면 그 샘플의 팝업은 한 개만 표시되고 예약한 시간이 모두 나열됩니다. 서로 다른 샘플은 샘플별 팝업으로 표시됩니다. 관리자가 해당 카드의 [관리자 확인]을 누를 때까지 팝업이 유지되며, 확인하면 사라집니다. 확인 상태는 Supabase 예약 데이터에 저장되어 새로고침 후에도 반영됩니다.

5. 예약 달력 및 관리자 일정
--------------------------------------------------
미팅 예약 아래의 월간 달력에서 예약, 관리자 일정 및 2026년 공휴일을 확인합니다. 날짜를 선택하면 해당 날짜의 일정을 볼 수 있습니다. 관리자만 일정명과 여러 시간대를 등록·수정·삭제할 수 있습니다. 일반 회원은 등록된 일정 내용을 조회할 수 있습니다. 관리 일정에 사용된 시간은 미팅 예약에서 선택할 수 없습니다. 공휴일명과 날짜는 빨간색으로 표시됩니다.

6. 미팅 완료 및 진도율
--------------------------------------------------
미팅이 끝나면 예약의 [미팅 완료]를 누릅니다. 완료된 예약은 미팅 목록과 오늘·이번 주 미팅 수에서 제외되며 시간이 다시 예약 가능해집니다.

생산시화 미팅 완료는 샘플을 CFM 어프로발 완료 상태 및 100%로 반영하고 CFM 진도율에도 포함됩니다. 전체 진도율은 생산시화 또는 재시화 미팅 완료를 반영합니다. CFM 진도율은 CFM 어프로발 또는 생산시화 미팅 완료를 반영합니다. 예약의 브랜드와 샘플명이 등록 샘플과 일치해야 해당 샘플의 진도율에 반영됩니다.

7. 내보내기
--------------------------------------------------
브랜드별 진도율의 [엑셀 내보내기]에서 선택한 시즌·브랜드의 진도 요약, 샘플 현황, 미팅 현황을 포함한 Excel 호환 .xls 파일을 내려받습니다.

8. 데이터와 운영 안내
--------------------------------------------------
인터넷 배포본은 GitHub Pages에서 화면을 제공하고 Supabase에 회원, 샘플, 미팅 및 일정 데이터를 저장합니다. 관리자 예약 확인 상태는 기존 예약 JSON payload에 기록하므로 이 기능을 위해 별도 DB 테이블이나 열을 추가할 필요가 없습니다. 최신 기능을 적용하려면 최신 웹앱을 배포해야 합니다. Egress 절감을 위해 화면을 켜 둔 상태에서 반복되는 전체 데이터 자동 조회를 중단했습니다. 다른 사용자의 변경 사항은 [실시간 동기화]를 눌러 확인합니다. 샘플 등록·수정 저장, 로그인, 미팅 가능 시간 확인 등 필요한 서버 요청은 계속 사용합니다.

날씨 인사말은 Open-Meteo를 우선 사용하고, 실패 시 wttr.in을 대체 조회합니다. 저장된 최근 조회값이 있으면 우선 표시하며 네트워크 조회에 실패하면 최대 6시간 이내의 캐시를 안내와 함께 표시합니다.
